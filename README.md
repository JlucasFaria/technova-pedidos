# TechNova Pedidos

Sistema de gestão de pedidos da **TechNova Soluções em Software**, utilizado como projeto-piloto na adoção da **Cultura DevOps** pela empresa.

## Descrição do projeto

A TechNova é uma software house de médio porte que desenvolvia e publicava suas aplicações de forma totalmente manual: o código era trocado por e-mail e pen drive, não havia versionamento e a publicação de uma nova versão dependia de uma pessoa específica executando comandos manualmente.

Este repositório é o projeto-piloto da consultoria contratada pela diretoria, reconstruindo o sistema de pedidos com versionamento, colaboração por branches, containerização e automação.

## Objetivo

- Implantar versionamento local e remoto com Git e GitHub
- Organizar o trabalho da equipe com branches e Pull Requests
- Padronizar os ambientes com Docker
- Automatizar os testes com um pipeline de Integração Contínua

## Tecnologias utilizadas

- Node.js 20 e Express
- PostgreSQL
- Docker e Docker Compose
- Git e GitHub
- GitHub Actions
